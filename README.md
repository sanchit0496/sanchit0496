# Hey, I'm Sanchit!

I'm a Software Engineering Specialist at Dassault Systèmes with 8+ years of experience building scalable web applications and backend systems. I enjoy designing clean architectures, building developer-focused tools, and solving complex engineering problems.

My interests span modern web development and AI engineering, with a focus on React, Next.js, Node.js, Retrieval-Augmented Generation (RAG), vector databases, local LLMs, and agentic AI systems. I enjoy building production-inspired projects that combine solid software engineering principles with practical AI applications.

Outside of work, I enjoy exploring system design, contributing to open source, and sharing what I learn through projects and technical content.
